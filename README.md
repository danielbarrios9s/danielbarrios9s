# 👋 Hola, soy Daniel Barrios

🚀 **Cloud Associate Architect | CTO en [Spectrum.IT](https://spectrum.it)**  
Apasionado por el diseño e implementación de soluciones **escalables, seguras y rentables** en la nube.  
Me enfoco en la **automatización de infraestructura**, la **optimización de entornos cloud** y la **integración de contenedores** para acelerar el desarrollo y la eficiencia operativa.

## 🧠 Enfoque Profesional

- **Arquitectura Cloud (AWS):** diseño de soluciones seguras y altamente disponibles.  
- **DevOps:** automatización de despliegues, CI/CD y gestión de infraestructura como código.  
- **Seguridad Cloud:** control de acceso, auditoría y políticas IAM.  
- **Contenerización:** despliegue de servicios en entornos Docker y Kubernetes.  
- **Optimización de Costos:** análisis y reducción de gastos operativos en la nube.
